用户模拟与 Persona 评测

Agent 产品上线前的中间层：用带画像的模拟用户，先筛体验与偏好问题

这篇在讲什么

这里的 simulation，指用大语言模型扮演带人格画像的「假用户」，在问卷、对话、网页或 App 里跑一遍，看产品和 AI 助手在不同人群上的完成率、满意度与偏好差。它介于传统 UX 调研与能力基准评测（如 SWE-bench）之间。

不包含机器人物理仿真、自动驾驶仿真，也不包含纯游戏 NPC 市场。腾讯 Persona Hub 一类项目主要服务合成训练数据，与「产品上线前测体验」相邻，但买家不同，下文单独标注。

为什么现在热

  • Agent 与 AI 产品迭代很快，真人人测贵、慢、难复现。
  • 传统 A/B 和分析工具偏事后；产品团队需要一层「上线前预测」。
  • 金融、医疗等垂直不敢公开乱试，模拟用户是合规叙事入口之一。
  • 实验室侧把 persona 当作训练与红队数据（如 NVIDIA Nemotron-Personas、腾讯 Persona Hub）。

市场怎么切

细分 典型问题 代表 商业形态
能力评测 模型能不能把任务做完 SWE-bench、WebArena、τ-bench 实验室与开源基准为主
Persona / 用户模拟评测 不同人用起来好不好、好不好感 MatrAIx、Blok、Uxia、Synthetic Users、Swarm、SimulatorArena 产品 / UX SaaS + 学术开源壳；近期创业融资相对集中
多智能体社会模拟 群体舆论、政策、传播怎么演化 Generative Agents、OASIS、AgentSociety、Artificial Societies 社科研究平台 + 企业传播 / 决策模拟

MatrAIx 落在第二类，人格池规模又碰到第三类的边缘。若押「评测基础设施」，要确认买家是做 Agent 的产品团队还是做模型的实验室；若押「合成用户」，要盯数据授权与模拟到真人的保真度。

开源与学术

Stanford Generative Agents（Smallville）

开源研究2023 UIST

用 LLM Agent 在类 Sims 沙盒里模拟 25 个角色的日程、记忆与社交，奠定「生成式 Agent 社会」范式。关键作者包括 Joon Sung Park、Joseph C. O’Brien、Carrie J. Cai（Google Research）、Meredith Ringel Morris（Google DeepMind）、Percy Liang、Michael S. Bernstein（Stanford）。

论文

腾讯 AI Lab · Persona Hub（Ge et al.）

开源数据合成训练

约 10.16 亿条从网页策展的 persona，主要用于大规模合成训练数据（数学题、指令、NPC 等），不是已验证的十亿在线用户产品评测。作者包括 Tao Ge、Xin Chan、Xiaoyang Wang、Dian Yu、Haitao Mi、Dong Yu（Tencent AI Lab Seattle）。论文 2024-06 首发，后续有修订。

论文 · GitHub

NVIDIA Nemotron-Personas

开源数据CC BY 4.0

按真实人口地理分布生成的多地区合成 persona；首发约 60 万（美国，2025-06），后续扩展多国，文档称集合达数千万级。主要用于模型训练、指令微调与安全红队。关键人包括 Yev Meyer、Dane Corneil（NVIDIA）；工具链来自并入 NVIDIA / NeMo 的 Gretel Data Designer。

介绍 · 数据集合集

OASIS（CAMEL-AI）

开源社会模拟

可扩展至约百万级 Agent 的社交媒体模拟器（类 X / Reddit），研究信息传播与极化等。论文作者包括 Ziyi Yang、Guohao Li 等。Guohao Li 另创办 Eigent AI（多 Agent 基础设施）；OASIS 本身以开源研究呈现。

站点 · 论文

AgentSociety（清华 FIB Lab 等）

开源社会模拟

大规模 LLM 社会模拟，带情感、需求、认知与城市 / 经济 / 社交环境；论文称可支撑逾 1 万 Agent、约 500 万次交互量级实验，用于极化、UBI、灾害等社科实验。通讯作者 Yong Li（清华大学）；一作含 Jinghua Piao 等。

论文 · 站点

Microsoft · SimulatorArena

开源基准EMNLP 2025

专门回答「用户模拟器能不能当真人多轮评测的代理」：909 段真人–LLM 对话（数学辅导 + 文档写作）；带用户画像的模拟器与真人评分 Spearman ρ 约 0.7；成本称不到真人约 3%。作者包括 Yao Dou、Alan Ritter、Wei Xu（Georgia Tech）以及 Michel Galley、Baolin Peng、Jianfeng Gao 等（Microsoft）。

论文 · GitHub

MatrAIx

开源 + 初创2026-08 论文

宣称约 83 亿条 persona 记录，配合问卷 / 聊天 / 网页 / App 四类环境做 AI 与数字产品的模拟用户评测；公开约 100 万条 coreset。论文 2026-08-04 上 arXiv；公司 LinkedIn 写 2026 年 Mountain View。CEO / Co-founder Xiaomin Li（Harvard 应用数学博士；履历含 DeepMind、Microsoft 相关岗位）；COO / Co-founder Yuexing Hao（Cornell 博士、MIT 相关履历）。

官网 · 论文 · GitHub

商业公司

Synthetic Users

SaaS2022

用多 Agent 与 OCEAN 等人格做合成定性研究（问题探索、概念与文案测试）；自称发现协作者而非替代真人，官网写 synthetic–organic 对齐率约 85–92%，并称 SOC 2。创始人 Kwame Ferreira、Hugo Alves。有 Comcast NBCUniversal LIFT Labs、Urban Innovation Fund 等投资痕迹；公开轮次金额未在可靠信源核实到具体数字。

风险与边界

  • Sim-to-real 差距。 SimulatorArena 显示：无画像的模拟器偏啰嗦礼貌；有画像后与真人评分相关性升至约 0.7，仍非 1.0。MatrAIx 也强调用途适配与真人收尾。ACL 研究「Quantifying the Persona Effect」称 persona 变量对主观标注方差的解释往往不到 10%。
  • 人格数量营销通胀。 Persona Hub「10 亿」、MatrAIx「83 亿」多为记录池或策展规模，不等于同时在线的评测用户数；尽调宜按「可抽样画像库」理解。
  • 数据权利。 公开 coreset / CC 许可与完整库商用权可能分离（例如 MatrAIx 公开约 100 万条）。
  • 大厂开源挤压。 NVIDIA、微软、腾讯与高校持续放出数据与基准，纯「人格库」难构成长期护城河；差异化更可能落在工作流嵌入（设计工具、分析埋点、合规交付）与行业垂直。
  • 买方分散。 UX 研究预算、Agent 评测预算、企业传播研究预算不是同一采购口袋。

投资视角

赛道本身成立：Agent 产品化叠加 UX 成本，模拟用户是自然的中间层；2025–2026 已有 Blok、Artificial Societies、Uxia、Swarm 等真金白银。

短期更像两条生意：「产品研发加速器 SaaS」和「企业传播 / 决策模拟」。「全球人口级评测基础设施」叙事仍偏学术包装。

尽调优先问：谁在付钱、是否有 ARR 或设计伙伴、有没有对照真人的 sim-to-real 实验、完整库授权怎么卖、是否依赖单一基础模型 API、与 Amplitude / Figma / CI 的嵌入有多深。

对标 MatrAIx：论文与开源扎实、履历亮，但公司极新，更接近「顶校开源项目挂壳」；需用客户、权利与保真度压营销数字。
